# SFT Core
整合包 Starter For Technology 的 Core Mod。
此 v8 分支是为适应即将到来的 GTM V8 设计的。

搭建环境需下载 GTMM 的 [最新 dev-slim 构建](https://github.com/QiuYe-123/GregTech-MoreMachine/releases)，并将其放入 `libs` 文件夹中，同时可能需要修改或删除 `gradle.properties` 中的 gradle 网络代理设置。
